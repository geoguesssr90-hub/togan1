# 陶眼 データ収集

天草陶石の等級判定AIを学習させるための、写真収集アプリです。

## 使い方
1. 「石を登録する」で石ID（自動採番）と等級を登録
2. 「乾燥」で各面を撮影 → 同じ面を水で濡らして「湿潤」で撮影
3. 撮影直後に画質チェック（ピンボケ・白飛び・影）が出るので、問題があれば撮り直す
4. 一覧画面の「学習用データを書き出す」でZIPを保存

## 撮影のコツ
- 撮影ボックス等で拡散光にし、直射光や影を避ける
- 白・グレーの基準カードを毎回同じ位置（画面右の黄色枠）に置く
- 1個の石につき、乾燥・湿潤それぞれ10枚以上を目安に

## 開発
```
npm install
npm run dev    # スマホから試すときは HTTPS が必要（下記）
npm test
npm run build
```
スマホのカメラは HTTPS でないと起動しません。Vercel にデプロイするのが手軽です（`npm run build` の出力 `dist/` をそのまま配信）。

## 注意
写真は端末のブラウザ内にだけ保存されます。ブラウザのデータを消すと失われるので、こまめにZIPで書き出してください。
